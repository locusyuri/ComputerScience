# C & C++ 笔记写作风格规范

## 一、语法规范

### 1.1 Typst 加粗语法
- ✅ 使用单星号 `*文本*` 进行加粗
- ❌ 禁止使用 Markdown 的双星号 `**文本**`
- 示例：`*时间复杂度*`、`*特点：*`

### 1.2 代码块
- 使用 ```cpp 标记 C++ 代码块
- 代码应包含注释说明
- 提供完整的可运行代码示例
- 示例：
```cpp
std::vector<int> v = {1, 2, 3};
for (int x : v) {
    std::cout << x << std::endl;
}
```

### 1.3 行内代码
- 使用反引号 `` ` `` 包裹代码元素
- 包括：函数名、类名、变量名、数据类型、关键字
- 示例：`std::sort()`、`std::vector`、`const`

### 1.4 标题层级
- `=` 一级标题（章节）
- `==` 二级标题（小节）
- `===` 三级标题（子小节）
- `====` 四级标题（知识点）
- 建议不超过四级


## 二、内容要求

### 2.1 内容具体详细
- **禁止空洞描述**：每个知识点必须包含具体内容
- **提供深入解释**：不仅要"是什么"，还要讲"为什么"和"怎么用"
- **包含实际示例**：每个重要概念都应有代码示例
- **对比分析**：相似概念进行对比说明

### 2.2 算法与数据结构
- 说明时间复杂度和空间复杂度
- 解释算法原理和适用场景
- 提供完整的代码实现
- 对比不同算法的优缺点

### 2.3 API 说明
- 说明函数/类的功能和用途
- 列出参数和返回值
- 提供使用示例
- 说明注意事项和常见陷阱

### 2.4 代码质量
- 代码格式规范（缩进、空格、命名）
- 使用有意义的变量名
- 包含必要的注释
- 遵循 C++ 最佳实践


## 三、结构规范

### 3.1 章节组织
- 逻辑清晰，层次分明
- 从基础到进阶逐步深入
- 相关内容归类到同一章节

### 3.2 列表使用
- 使用 `-` 进行无序列表
- 使用 `1.` 进行有序列表
- 列表项应简洁明了

### 3.3 表格使用
- 用于对比数据（如算法复杂度对比）
- 表头清晰，内容对齐
- 示例：

| 算法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|------|-----------|-----------|--------|
| `sort` | O(n log n) | O(log n) | 不稳定 |
| `stable_sort` | O(n log² n) | O(n) | 稳定 |


## 四、语言规范

### 4.1 语言一致性
- 使用中文写作
- 专业术语前后一致
- 代码注释使用中文

### 4.2 简洁明了
- 避免冗长和重复
- 使用简洁的句子结构
- 重点内容突出显示

### 4.3 准确性
- 技术内容准确无误
- 代码示例可运行
- 引用标准和规范
