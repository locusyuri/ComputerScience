## 编写原则与风格规范

### 内容要求

#### 内容深度

- **禁止空洞描述**：每个知识点需包含具体内容
- **深入解释**：不仅要"是什么"，还要"为什么"和"怎么用"
- **包含实例**：每个重要概念都应有代码示例
- **对比分析**：相似概念进行对比说明

#### 算法与数据结构

- 说明时间复杂度与空间复杂度
- 解释算法原理和适用场景
- 提供完整的代码实现
- 对比不同算法的优缺点

#### API 说明

- 说明函数/类的功能用途
- 列出参数和返回值
- 提供使用示例
- 说明注意事项与常见陷阱

#### 代码质量

- 代码格式规范（缩进、空格、命名）
- 使用有意义的变量名
- 包含必要的注释
- 遵循对应语言的最佳实践

### 示例语言偏好

编写示例代码时，若未指定语言：
- 数据结构相关的优先使用 C++
- 其他情况推荐使用 Kotlin

### 语言规范

- 使用中文写作
- 专业术语前后一致
- 代码注释使用中文
- 简洁明了，重点突出
- 技术内容准确无误，代码示例可运行

### 检查清单

完成内容后检查：

- [ ] 所有加粗使用单星号 `*文本*`
- [ ] 代码块使用正确的语言标记（如 ```cpp）
- [ ] 行内代码使用反引号
- [ ] 数学变量用引号包裹：`$"length"$`
- [ ] 复杂度表示使用数学模式：`$O("log n")$`
- [ ] 内容具体，有实际示例
- [ ] 算法说明包含复杂度分析
- [ ] 代码示例完整可运行
- [ ] 章节结构清晰合理
- [ ] 语言简洁准确
